# Amazon Sales Analytics

## Project Overview

This project demonstrates an end-to-end Business Analytics workflow using Microsoft Excel, SQL (PostgreSQL), and Power BI. The project analyzes Amazon sales data to identify sales trends, customer behavior, product performance, and business insights through interactive dashboards.

## Tools Used

- Microsoft Excel
- SQL (PostgreSQL)
- Microsoft Power BI

## Project Objective

To analyze Amazon sales data and build an interactive dashboard that supports data-driven business decision-making.
